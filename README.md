# Team Purrfect - NUS x NTU Databusters 2026 Project
Repository for Team Purrfect's documents for NUX x NTU Databusters 2026.

## Project Description
An examination of financial runs across two crises: the 2008 Reserve Primary Fund collapse and the 2022 Terra-Luna stablecoin failure.
More information can be found in the official Case Prompt uploaded into the repository.

## README
Instructions for setting up the environment, running our notebook and reproducing the results
1. Upload both ERC20-stablecoins and gfc zip files onto the same google drive as the google collab.
2. Upload “token_transfer.csv” from the gfc file into the files tab of the notebook.
3. Run the notebook
4. Allow google collab to access your google drive.

Unfortunately, the datasets were unable to be uploaded into the Github repository due to a large file size.
Instead, they have been uploaded into Kaggle here:
- ERC20-stablecoins: https://www.kaggle.com/datasets/yilunn/erc20-stable-coins
- gfc: https://www.kaggle.com/datasets/yilunn/global-financial-crisis
